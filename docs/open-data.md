# Open Data

All pid4cat metadata is published under the [CC0 1.0 Universal Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/).
The handle record of every pid4cat PID on the Handle server, including its metadata, can be read without authentication through the [Handle.net API](./apis.md#handlenet-api).

## PID Graph integration

The PID Graph connects persistent identifiers of different types into a network of scientific and scholarly entities.
pid4cat contributes to it by:

1. Recording relations to other PIDs in its metadata
2. Using relation types adapted from the [DataCite metadata schema](https://datacite-metadata-schema.readthedocs.io/)
3. Exposing metadata in machine-readable formats
4. Linking resource categories and relation types to concepts of the [Voc4Cat](https://nfdi4cat.github.io/voc4cat/) vocabulary
